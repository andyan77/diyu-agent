## 逐项点击验收

### 1. 企业管理工作区

1. 用 `package7-sim-owner-admin` 登录 `/apps`。
2. 依次点击“企业资料、组织与人员、账号矩阵、使用情况、系统状态”。
3. 应看到真实模拟企业状态、组织与绑定人员、11 个内容账号、请求次数与最近活动，以及网页、资料、检索、模型和导出状态。
4. “企业资料”和“组织与人员”不应出现假新增、上传或删除按钮；任何栏目都不应出现候选正文或内容审核队列。
5. 在账号矩阵新增一个可扩展模拟账号，确认绑定使用人登录后可见，再将该账号停用；固定三类账号不能重复创建。

### 2. 首页差异、自然对话和确认卡

1. 分别登录总部品牌、创始人、商品人设、省级代理、直营门店和加盟门店代表账号，查看首页 3 至 5 个推荐方向；推荐应随账号和人设明显变化。
2. 用 `package7-sim-owner-product` 登录，确认顶部同时显示登录人、岗位、组织、长期人设和对外账号；手机宽度也应可见。
3. 在主输入框写“今天顾客在两套搭配之间犹豫，我想讲清我们怎么帮她判断”，点“陪我想”。
4. 应先得到 2 至 3 个普通语言角度。选一个角度后，应进入可直接修改的“系统已经理解”确认卡。
5. 展开“更多调整”，改变平台、长度、主要受众、表达感觉和成品；生成结果应使用这些选择。
6. 回到首页点“只是聊聊”，系统应作为普通聊天回应，不强行进入内容生成。

### 3. 快速填写、例子和提示词

1. 展开“快速填写”，应只有“谁来讲、手里有什么、做成什么、希望带来什么”四步，每步不超过六个通俗选项。
2. “手里有什么”选择“图片或视频线索”只表示用户手里有线索，页面不得声称文件已经上传或读取。
3. 展开“看看例子”，任选一个方向，再写自己的主题；结果应围绕本次主题，不复制固定范文。
4. 依次点“帮我想／帮我做／帮我改”，它们只应改变输入提示和表达视角，不应变成三个并列系统。

### 4. 七种成品、三集系列和结果工作台

1. 在同一个主题上依次选择：短视频、图文、直播内容包、私域沟通内容、门店线下物料、培训与门店话术、陈列搭配。
2. 每种成品应出现适合自身用途的结构；“陈列搭配”不能只是把短视频换标题。
3. 选择“三集系列”后立即点生成：必须先完整显示三集提纲，随后才发送并展示第 1 集；第 1 集完成后可继续下一集。
4. 结果页应有 2 至 3 个真正不同的候选。点选候选后，可输入一句自然语言做局部修改、回看上一版、换角度、换成品、复制或导出。
5. 未选择候选直接导出时，应提示“尚未选择候选”；不应要求填写候选编号。
6. 全程不应出现送审、批准、审核队列或导出前确认门；系统也不会自动发布到外部平台。

### 5. 隔离、错误提示和 Dify 技术画布

1. 同时开两个无痕浏览器，登录两个不同账号。一个窗口生成的候选不能在另一个窗口查看、修改或导出。
2. 退出后刷新，应提示“登录已失效”；缺少必要一句、未选候选和系统暂时故障应使用不同提示。
3. 用安全凭据包中的 Dify 管理成员登录根入口 `/`，应能打开当前唯一笛语应用画布；企业管理员登录 `/apps` 时不应获得这个技术权限。

## 20 条通俗自然语言试题

操作方式：在首页“搜索其他内容方向”选择表中名称，再输入右侧试题并点“陪我想”。页面不显示内部编号；确认卡或结果页应显示所选通俗内容产品。

| 内容方向 | 可直接输入的试题 |
|---|---|
| 岗位任务视频日志 | 记录我今天把一批新品从到货信息核对到交给门店上架的工作过程。 |
| 门店时段微纪录 | 想拍杭州滨江店从开门准备到午后第一波顾客进店的一小时。 |
| 单项手艺全过程 | 完整讲一件童装的纽扣从定位、缝制到最后检查是怎么完成的。 |
| 多岗位协作纪实 | 记录设计、商品和门店三方怎样一起解决一次新品陈列问题。 |
| 人物成长与职业史 | 讲讲一位店员从不敢开口介绍商品到能独立服务顾客的变化。 |
| 专业判断切片 | 顾客在两件外套之间犹豫时，我们通常根据哪些条件做判断？ |
| 用户问题诊断室 | 家长问孩子个子长得快该怎么选尺码，帮我把问题一步步讲清楚。 |
| 工艺、面料和版型解构 | 用普通人听得懂的话解释这件衣服的面料、版型和走线各有什么作用。 |
| 适用边界与反选指南 | 这款衣服更适合什么场景，又有哪些孩子或需求不一定适合？ |
| 长期使用与验证记录 | 想持续记录一件外套穿过一个季节后的舒适度、打理和变化。 |
| 产品诞生与设计取舍 | 讲讲一款新品从最初想法到定稿，中间放弃了什么、保留了什么。 |
| 产品迭代与版本日志 | 同一款裤子新旧两版有哪些调整，为什么要这样改？ |
| 产品的生活与衣橱角色 | 这件针织开衫在孩子一周生活和现有衣橱里能承担什么角色？ |
| 物性影像与感官短片 | 不靠夸张文案，怎样用画面表现这块面料的触感、垂感和颜色？ |
| 商品到店生命周期 | 记录一批商品从到店、拆箱、整理、上架到被顾客看到的全过程。 |
| 真实服务复盘 | 复盘今天我们怎样帮助一位顾客在两套搭配之间做出选择。 |
| 陈列换陈与空间实验 | 记录门店把入口陈列重新调整前后的思路、动作和空间变化。 |
| 城市门店生活志 | 讲讲苏州这家店和周边街区在一个普通周末里发生的生活片段。 |
| 经营取舍与决策复盘 | 复盘一次门店活动为什么没有追求更大规模，而选择先服务好老顾客。 |
| 承诺与兑现追踪 | 持续记录我们答应改善的一项服务，从提出到真正落实经历了什么。 |

## 验收边界

- 所有生成内容都是当前使用人的候选稿，可自行修改和决定是否使用；没有企业内容审批。
- `automatic_publish=false`、`public_self_registration=false`、`real_customer_data_imported=false`。
- 300、120、86 三个历史数字没有重跑、改写或受损；所有 readiness flags 保持 `false`。
