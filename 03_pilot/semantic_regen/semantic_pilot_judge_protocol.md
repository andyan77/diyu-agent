# Semantic Pilot Judge Protocol

This protocol is for the 20 regenerated semantic pilot drafts only. It does not approve batch generation by itself.

Judge dimensions:

1. Proposition independence: each card must be more than a title or cluster-id variation.
2. W7 cluster entailment: the cluster must change the mechanism, object/action, risk, evidence need, or output effect.
3. Industry density: the body must contain apparel objects, retail scenes, content actions, display or styling actions, evidence boundaries, failure modes, operator decisions, and downstream implications.
4. Relation specificity: relation predicates must describe functional semantics, not adjacency.
5. Source boundary correctness: provenance class and human review status must remain separate.
6. Non-template body: normalized body signatures must be independent.
7. Future batch exemplar value: judge may approve, request revision, or reject.

Go/no-go options remain pending until a human or independent judge records a decision. Batch generation remains locked.
