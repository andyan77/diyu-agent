# G3 受控作者指令 v2.1（第2正式轮）

v2.0 全部条款继续有效（事实与授权边界、边界事实化呈现、指纹义务、组件表面
真实消费、精确语义输出合同、身份与运行纪律）。本版新增两节，来源于第1正式轮
四位独立内容审查者的一致发现：**边缘互异、内芯同构**——开场/标题/收尾各不相同，
但正文架构、口播句式、声音设计、边界句族在同产品内收敛成同一模板。

## 三A、四维深层档型（强制）

`expression_plan` 新增四个字段，逐项落实：

- `body_architecture` 正文架构：CHRONO_SINGLE_THREAD=单线时序；
  CONTRAST_TWO_OBJECT=双对象对照交替；MOSAIC_THREE_SCENES=三个独立小画面拼合
  （无"先/再/然后"串词）；CAUSAL_CHAIN=现象→机制→后果；
  ZOOM_DETAIL_TO_WHOLE=细节逐层放大到整体；EVIDENCE_WALK=跟随一件实物/一页记录走。
  **架构决定段落之间的关系**，不是换个开头就算。
- `spoken_format` 口播格式：EMPTY_NO_SPOKEN（此时声音轴组件指针落在
  audio_execution 表面并绑核心事实）；SINGLE_OBSERVATION；TWO_VOICE_EXCHANGE；
  COUNTED_REPORT（数值全部出自材料）；QUESTION_ECHO；PROCESS_MURMUR。
- `audio_signature` 声音设计：AMBIENT_CONTINUOUS / ACTION_ACCENTS /
  SINGLE_MARK_SOUND / LAYERED_NEAR_FAR / QUIET_ONE_BREAK / RHYTHMIC_TASK。
  声音表面的写法要体现所选签名，不得都写成"依次成为小段声音标记"。
- `boundary_position` 限度位置：EARLY_WEAVE / MID_WEAVE / LATE_FACT /
  SPLIT_TWO_POINTS / VISUAL_CARRIED / SPOKEN_CARRIED。
  限度句措辞家族也要随位置变化——**"这只是…还没…"句族同产品全批至多出现1条**。

## 三B、内部反模板纪律（强制，机器与人审双查）

第1轮被判死的骨架，全部禁用：

1. **证据名录式段落**（"版师只…样衣工只…没有谁去认证"式逐岗排比）——
   证据要长在叙事里，不要列队报数。
2. **否定边界排比**（"不是A也不是B""只说明X说不上Y"连续出现）——
   每条内容至多一处否定式限度，其余限度用肯定式事实句（"复测排在面料回缩之后"）。
3. **缺料静默句**（"画面里没有的就没有""能说的就这些"）——直接删除，
   不写"我没写什么"。
4. **合成披露语句内嵌正文**（"这家门店是合成的"写进 body/spoken/visual/audio）
   ——披露只存在于专用披露表面，正文里出现即机器硬失败（E_G3_DISCLOSURE_IN_BODY）。
5. **跨条句式复用**：与同批同产品其他条目共享 ≥10 字的非材料连续片段会被机器
   标记（F_G3_CROSS_OUTPUT_REUSE）。你看不到别人的输出，防御方法是：把你自己
   6/3 条里用过的句式、转场词、收尾措辞逐条错开，绝不复制自己上一条的任何句子。
6. **代价/限度母题措辞**：每条换不同的表达方式（数字对照/时间推移/身体感受/
   空间变化/他人反应），不用同一句型换名词。

## 三C、完备性自检扩展（机械项，允许运行）

形状自检脚本另附完备性检查（核心事实全部绑定到表面、每个批准组件的指针
角色兼容且槽位绑定成立）。这两项是登记完备性（第1轮 CP16 因漏登记被机器判死），
与内容质量无关，跑到零错误再交付。
