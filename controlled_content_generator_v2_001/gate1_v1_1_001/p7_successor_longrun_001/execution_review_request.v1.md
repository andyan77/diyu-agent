## 四、根因（跨四轮同一失败轴，第 4 次独立复现）

**机制 = "打地鼠"（whack-a-mole）**：每轮用门精确封死上一批收敛的**承载位/句族**后，
众多作者在下一个尚未被门覆盖的**语义槽位**重新收敛出替代家族。

- R1：正文架构/口播/声音/边界句在同产品内收敛 → R2 加四维深层档型 + 每 CP 双作者。
- R2：档型互异但限度句族/声音行话/整条骨架收敛（根因锁策展层措辞单一）→ R3 边界事实按 6 风格重策展 + 反行话/判死骨架指令。
- R3：边界句面发散，但收敛挤到"限度/收尾叙事壳"，实现为**末段可分离免责节拍**（"排在后面工位/那几栏空着/要走正式测试才算数/取景之外/没人来问"）→ 执行包5 加**结构位置门 END_BOUNDARY_DISCLAIM** + v2.3 三H 收尾正向锚定/三I 界限溶景/三J 整条骨架互异。
- R5（执行包5）：**末段免责节拍这一具体承载位被真封死**（机器 0 命中、CP01/02/03 全清为证），
  但同一"缺料静默/泛化免责"语义家族**迁移到前一段正文/口播/画面**，第 3 轮致死原词大面积换位复现。

**结构性根因**：不在任何单一句族或承载位，而在生成结构本身——众多作者用**同一批
typed_material、同一组边界事实、同一套发牌骨架**填**同一批语义槽位**，凡未被机器 HARD
强制发散的槽位必然坍缩到共同输入所隐含的同一修辞动作。逐轮封死具体承载位只是把同一
收敛不断赶到下一个槽位，从未改变"多作者共同输入 → 语义槽坍缩"这一根因。

## 五、诚实负面发现（不粉饰，含定域成功与副作用）

1. **定域成功是真实的**：CP01/CP02/CP03 各 6/6 全接受（21 条可接受中 18 条来自这 3 个 CP）。
   v3.1 三H/三I 对**单主体、工序天然线性**的档型（岗位 VLOG / 门店时段微纪录 / 单项手艺
   全过程）真正消除了收敛——收尾落进行中场景/前向价值，旧免责节拍溶入实景。方向可行。
2. **强度/覆盖严重不足**：其余 17 个 CP（多要素协作/判断切片/边界反选/复盘/城市生活志等）
   的限度表达仍在任意剩余槽位重新同构。18/120 距 90% 差距巨大。
3. **正向合同的副作用（设计教训）**：修末段免责节拍的三H"末段必须落前向价值动作"合同，
   诱发了一类**新的编造**——CP20-001 为满足该合同，硬造出"客服把 4 位空号排进电话回访"
   的动作，既无源、又与源事实"空号（号码无效）改发站内信"直接矛盾。正向约束会把作者
   逼向编造以填充要求的动作槽。
4. **纤维核源仍缺机器层确定性门**：5 条事实硬否决中 3 条为纤维/材质编造（"粗棉纹"/"棉层"/
   无源耐久），与 R3"羊毛混纺"同族；当前仅靠人审兜底，机器门未覆盖"纤维成分∉facts"。
