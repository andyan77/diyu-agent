# 源仓 ↔ 产品仓单向测试协议 v1（SOURCE_TO_PRODUCT_TEST_PROTOCOL）

> 真源：D0 §⑤ + v2.4 §四 4.3。方向唯一：**源仓 → 产品仓**。

## 1. 允许的流向

1. 源仓测试语料（非密封开发样例、合成 fixture）经**适配器**挂载进产品仓测试环境；
2. 源仓向产品仓推送 allowlist 内代码（经 CROSS_REPO_LIFT_MANIFEST）；
3. 产品仓验收结果以**报告摘要**形式回源仓证据目录登记（只读回执，不含产品运行态数据）。

## 2. 禁止的流向

1. 产品运行输出写入源仓任何路径（单向纪律，v2.4 §二-4）；
2. 产品仓代码/配置回流覆盖源仓实现（修复必须在源仓完成后重新走抽取链）；
3. 产品仓测试直接 import 源仓模块或引用源仓绝对路径（hermetic 破坏，clean-room profile 拦截）；
4. 密封材料以"测试语料"名义流入产品仓（denylist 撞库拦截）。

## 3. 适配器纪律

- 适配器只做形状转换与路径重绑定，不改语义；适配器代码属产品仓，随 lift manifest 登记；
- 测试语料清单逐文件 sha256，与产品仓测试运行回执绑定；
- 语料若源自领域数据，必须先经 denylist 校验证明不在禁运类别。

## 4. 机械执行

- `tools/lift_chain.py check-dependency-direction`：产品树中源仓路径引用零命中；
- 产品仓 CI（交付后）不访问源仓远程；
- 源仓 checker `write_surface` 节确保产品验收回执只落证据目录。
