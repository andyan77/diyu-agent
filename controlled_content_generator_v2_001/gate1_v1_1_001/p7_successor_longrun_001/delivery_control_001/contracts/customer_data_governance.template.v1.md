# 客户数据治理模板 v1（产品内置治理模板 · 交付出口件）

> 真源：v2.5 §二（#11，客户数据边界扩至 Git 之外）+ D0 §⑥ + P1 §十八。
> 执行侧现阶段**零客户数据**（红线维持）；本模板是交付物的产品功能要求，随 M5/M7 交付实例化。

## 1. Git 边界（红线）

客户数据不得进入任何 Git 仓（源仓与产品仓）；负向测试用**合成数据**（`tests/test_negative_attacks.py` 合成标记 `SYNTH-CUSTOMER-MARKER`）。

## 2. 产品默认配置边界

| 通道 | 默认策略 | 机械可测点 |
|---|---|---|
| 日志 | 不落客户数据明文；默认脱敏（字段级掩码） | 日志采样扫描合成标记零命中 |
| 遥测 | 只发聚合计数与摘要 | 遥测 payload schema 禁自由文本客户字段 |
| 缓存 | 客户输入缓存默认关闭；开启须显式配置+保留期 | 缓存目录扫描 |
| 备份 | 不含客户数据明文；含则必须加密+保留期策略 | 备份清单审计 |

默认保留期策略：客户输入运行态即用即弃；任何持久化须显式配置并登记保留期与删除路径。

## 4. 交付验收

- 交付文档含"客户数据不出声明边界"声明与本模板实例；
- 合成数据负向测试通过（合成客户标记注入 → 日志/遥测/缓存/备份四通道零明文泄出）；
- 未含上述项 = 交付出口不过。
