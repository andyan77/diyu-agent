# Calibration

本目录只登记 M0 开发集与密封资格集的状态、用途和访问边界，不存放伪造案例、占位金标或虚构资格结果。

## 当前事实

- 评测参考实现与开发回归规则：已物化并通过本地反向测试，但未校准；
- 开发金标集：未物化；
- 密封资格集：未物化；
- 双审与裁决：未执行；
- 测量报告：不存在；
- M0：`NOT_QUALIFIED`。

`M0_STATUS.v1.json` 是当前资格状态真源。两个 manifest 的 `manifest_digest`、源摘要和金标摘要保持 `null`，直到真实文件物化后由未来运行器按合同计算；不得用全零摘要或随意字符串冒充冻结。

## 数据边界

### 开发集

属于 `G2_MEASUREMENT_DEV`，允许评测开发者用于量规、抽取、主张原子化、蕴含、语义候选召回和省略检测调试。它只能作为开发与回归证据，不能作为 M0 密封资格证明。

### 密封资格集

属于 `G3_MEASUREMENT_QUALIFICATION`。资格答案不得提供给评测开发者、量规开发者、生成器开发者或作者。若发生泄漏，受影响案例整组失效，只能降级为开发回归，并重新建设全新密封集。

## 物化要求

未来物化前必须先具备：

1. 数据保全者、两名独立标签者和第三裁决者；
2. 明确且互不重叠的源案例清单；
3. 逐案例源区间、授权和风险等级；
4. 参考断言、主张原子、三值蕴含、套路对和披露义务标签；
5. 访问与复制事件；
6. 来源清单和金标清单摘要；
7. 泄漏扫描与角色碰撞检查；
8. 与 `measurement_qualification.v1.json` 一致的分母。

## 禁止事项

- 不得把 R1-R5 已见案例原样计作新的密封资格案例；
- 不得在看到资格答案后调阈值再复用同一答案报通过；
- 不得只登记正确案例而删除失败或弃权；
- 不得将开发集统计与密封资格统计合并；
- 不得在没有独立裁决报告时改变 `M0_STATUS`。
