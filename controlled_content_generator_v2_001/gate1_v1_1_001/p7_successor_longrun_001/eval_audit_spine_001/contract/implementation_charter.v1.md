# 可信评测与审计脊柱实施章程 v1

## 1. 目的

建立一条可复用的评测与审计脊柱，先证明评测系统自身的误差边界，再把它用于第一门生成器恢复。章程不授权正式内容编排计划、企业运行数据库、批量生成、部署或发布；外部调用仅限发起人另行批准的 DeepSeek 套路语义评审用途，并受 30 元人民币/UTC 日硬预算约束。

## 2. 不可变边界

1. R1、R2、R3、R5 及其失败分母保持原样，不得追溯翻绿。
2. V1.1 的首次可接受率、套路率、全批硬否决、盲判、路线与审计要求不因实现困难而降低。
3. 机器相似度只召回疑似对，最终套路结论由操作化量规的独立评审确认。
4. 自动参考断言、主张原子和蕴含结论都是概率层；未独立校准不得冒充真值。
5. 合成身份和禁冒真披露不软化；省略式误导另设概率检测与人工裁决。
6. 没有获批预算、完整成本事件和停止条件，不得进入规模阶段。
7. 第一门内部测试分配单不得冒充第二门正式内容编排计划。
8. 外部评审每次调用必须先预占最坏费用、再按提供方令牌回执和冻结费率结算；回包不合约也要结算和留痕，但不得进入评审集。

## 3. 核心对象及所有者

| 对象 | 所有者 | 性质 | 是否可直接硬拒绝 |
|---|---|---|---:|
| `source_evidence_unit` | 数据保全角色 | 确定性源区间 | 仅形状、摘要和区间错误 |
| `reference_assertion` | 金标建设与裁决角色 | 提议为概率，双审后为裁决参考 | 未双审不可 |
| `claim_atom` | 独立原子化角色 | 概率提议 | 不可 |
| `entailment_finding` | 评测器 | 概率发现 | 自然语言结果不可直接形成最终硬否决 |
| `formulaic_candidate_edge` | 候选召回器 | 概率发现 | 不可 |
| `formulaic_adjudication` | 内容评审与裁决者 | 独立评审结论 | 可进入最终人工判定 |
| `disclosure_finding` | 确定性规则或省略检测器 | 混合 | 只有确定性义务缺失可自动硬拒绝 |
| `gate1_test_assignment` | 第一门测试分配器 | 资格测试控制元数据 | 不适用 |
| `cost_event` | 运行编排者 | 确定性计量 | 缺失时阶段关闭失败 |
| `stage_decision` | 独立审计者/发起人 | 治理结论 | 决定继续、停止或请求修订 |

## 4. 依赖方向

```text
schema / contract
      ↓
source evidence preservation
      ↓
reference assertion proposal → independent adjudication
      ↓
claim atom proposal → entailment / disclosure / formulaic candidates
      ↓
balanced review assignment → adjudication
      ↓
calibration + cost + immutable audit manifest
      ↓
stage decision
```

评测脊柱不得导入某个具体生成器的内部规划模块。生成器可以输出通用候选对象供脊柱消费，但正式资格模式不得在首个响应前读取评测反馈。

## 5. 第一门测试分配单

`gate1_test_assignment` 只能描述资格测试变量：产品编号、家族、材料摘要引用、论证关系、证据表面策略、视角/时间锚、限度承载方式、收尾功能、配对编号和禁止推断。

它必须同时写明：仅用于第一门合成资格、不可运行、不可发布、不绑定企业输入、不计入 300、不是正式内容编排计划。模式采用 `additionalProperties: false`，从形状上阻止添加租户运行绑定、发布目标或正式编排状态。

同一案例只能有一个冻结分配摘要。测试材料不得再携带独立的结构或边界风格发牌；请求构造器不得依据新批次编号重新偏移任何结构维度。

## 6. 表面策略与反编造

`MUST_SURFACE / MAY_SURFACE / CONTROL_ONLY` 是统一分配器的一次联合决策：

- `MUST_SURFACE`：产品成立、主张成立或披露义务所需的最小事实；
- `MAY_SURFACE`：合法但不必逐条消费的支持事实；
- `CONTROL_ONLY`：不给受众直接看，但继续约束作者与验证器的事实、禁配、前置条件和权限边界。

若省略某项会使合理读者形成实质性错误理解，该项不得留在 `CONTROL_ONLY`，必须提升为 `MUST_SURFACE`。减少受众表面不等于减少事实约束。

## 7. 资格与停止

M0 是后续生成器恢复的前置条件。M0 未通过时，可继续建设合同、金标和测量工具，但不得对外宣称“可信评测”，不得用概率结果自动定罪，也不得进入隐藏或 300 规模。

同一测量构念只允许初版加一次冻结修订（共两个方法版本）。达到预算或修订上限仍不合格时，必须选择：

1. 退回纯人工全审并重新计算成本；
2. 请求显式量规/标准修订；
3. 诚实停止。

## 8. 标准修订出口

材料不足、测量构念不可靠和系统能力不足是不同失败类型。它们不得互相冒充：

- 材料不足：定向补料或缩小明确授权范围；
- 测量不可靠：修订量规或停止自动门；
- 系统在批准预算内不可达：停止或换架构；
- 更高优先真源改变：显式发布新标准版本。

任何新版本只前瞻生效，不能改变既有 R5 失败判定。

## 9. 当前声明

本章程完成不等于实现或资格完成。无论运行模块是否另行并行物化，只要尚未通过独立实现审核、未物化金标、未执行资格测试或未批准预算，M0 就必须保持 `NOT_QUALIFIED`。
