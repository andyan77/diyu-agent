# 证据链与事实裁决量规 v1

## 1. 用途

本量规用于建立和审核：源证据单元、裁决参考断言、候选正文的原子主张以及三值语义结论。它不把自动抽取或语言模型判断称为 ground truth。

## 2. 四类对象

### 2.1 源证据单元

源文件中可由摘要、字节起止位置和原文机械复核的最小连续区间。区间、原文和摘要属于确定性保全对象；对区间“意味着什么”的解释不属于确定性层。

### 2.2 参考断言

从一个或多个源证据单元归纳出的实体—属性—关系断言，必须记录：

- 主体、谓词和值；
- 数值、单位和量词；
- 时间范围；
- 极性；
- 情态：观察、转述、计划、可能或未知；
- 前置条件；
- 来源区间和授权；
- 风险等级；
- 抽取来源和验证状态。

自动抽取只产生 `PROPOSED`。只有两名独立建设者一致，或经第三角色裁决，才能成为 `DUAL_ADJUDICATED` 裁决参考。

每份审查记录必须同时绑定断言对象摘要、完整证据编号集合，以及按证据编号排序的证据对象摘要清单。只写证据编号、自由文本“已核对”或任意摘要，不构成证据闭包；证据片段变化后旧审查记录必须失效。

### 2.3 原子主张

候选文本中能够单独判断支持状态的最小命题。标题、正文、口播、画面说明、声音说明和行动号召均纳入原子化。作者自报主张只用于候选定位，独立原子化不得直接复制作者清单后宣称完成。

拆分原则：

1. 不同主体、谓词、时间、条件或极性原则上拆开；
2. 一个句子同时断言材料成分与耐久效果时必须拆成两个主张；
3. “将要”“可能”“已经”“每次”“六次都”等情态和量化不可丢失；
4. 画面或声音说明若暗示真实物体、动作或结果，同样形成主张；
5. 纯格式、无事实含义的合成身份披露不进入普通事实主张，但接受单独披露硬门。

### 2.4 蕴含发现

每个原子主张只使用以下三种语义标签：

- `SUPPORTED`：裁决参考集在相同主体、谓词、时间、条件、极性和情态下足以支持；
- `CONTRADICTED`：裁决参考集机械或经语义裁决证明其相反、互斥或不可能同时成立；
- `UNKNOWN`：没有足够支持，也没有足够证据证明相反。

模型不确定、参考集本身未完成裁决或模型之间冲突时，`semantic_label` 留空并设置 `abstain=true`。`ABSTAIN` 是处理动作，不是第四个事实真值。

## 3. 判定程序

对每个原子主张按以下顺序执行：

1. 确认文本区间和表面类型；
2. 识别主体、谓词、值、单位、时间、条件、极性和情态；
3. 检索所有可能相关的已裁决参考断言；
4. 先检查结构化明确矛盾，再检查语义支持；
5. 证据不足时判 `UNKNOWN`，不得为了减少未知而补造事实；
6. 概率模型低置信、分歧或参考集不完整时弃权并送审；
7. 记录引用区间、判断理由、模型与提示版本、调用回执和评审状态。

## 4. 高风险主张类型

以下类型默认 `HIGH` 风险，资格集必须定向覆盖：

- 纤维、成分、填充物、涂层、认证或工艺材料；
- 耐久、寿命、不变形、防护、功效和结果承诺；
- 数字、频次、比例、绝对量化和群体偏好；
- 已发生或将发生的回访、联系、承诺、补偿和运营动作；
- 顾客、员工、门店、品牌、商品、库存和真实事件；
- 授权、隐私、跨租户和身份；
- 将询问、观察或个例扩大为群体规律；
- 将计划、可能或待验证写成已经完成或确定有效。

## 5. 结构化确定性矛盾

只有在以下条件全部满足时，机器可输出 `DETERMINISTIC_HARD`：

1. 相关参考断言已 `DUAL_ADJUDICATED`；
2. 主张字段能够无歧义结构化；
3. 冲突由明确值、极性、单位、时间、授权或互斥状态机械证明；
4. 不依赖常识补全或开放语义推断；
5. 规则具有正向和反向测试。

其余自然语言矛盾只能输出 `REVIEW_REQUIRED`。例如“空号”与“已电话联系成功”的关系需要确认时间、渠道和动作语义，不因词表命中就直接自动定罪。

## 6. 常见错误

| 错误 | 后果 | 正确处置 |
|---|---|---|
| 把未抽出的源事实当不存在 | 假 `CONTRADICTED` 或假 `UNKNOWN` | 单独计算参考断言漏抽率 |
| 把复合句只拆成一个主张 | 高风险子主张漏检 | 逐主体/谓词/条件拆分 |
| 把“不知道”写成“不存在” | 假矛盾 | 维持 `UNKNOWN` |
| 把未来计划写成已完成 | 假支持 | 保留情态与时间 |
| 只检查正文，不检查画面/声音/标题 | 编造从其他表面漏过 | 全表面原子化 |
| 直接信任作者 fact_id | 假支持 | 独立验证文本语义与证据关系 |
| 多个概率模块共用同一模型且不披露 | 相关错误被低估 | 报告模型复用与端到端误差 |

## 7. 金标建设

1. 两名建设者独立读取相同源证据，不读取彼此标签；
2. 先标参考断言，再标原子主张，再做蕴含；三个步骤分别保留首判；
3. 分歧由第三角色只看源证据、首判和量规进行裁决；
4. 开发金标与密封资格金标分格存放；
5. 每次量规变更只更新版本，不覆盖旧标签；
6. 资格集必须包含真实失败、定向变体、合法近邻和难负例。

## 8. 资格报告

必须分别报告：参考断言精确率/召回率、关键字段正确率、主张原子化精确率/召回率、错误合并率、三值混淆矩阵、弃权率、端到端高风险漏放、FP/FN 明细和 95% 置信区间。

任何单模块通过都不能替代端到端通过。高风险漏放大于零时 M0 失败。

## 9. 当前状态

本量规尚未通过金标校准。它是待验证的判定程序，不是已经可靠的事实门。
