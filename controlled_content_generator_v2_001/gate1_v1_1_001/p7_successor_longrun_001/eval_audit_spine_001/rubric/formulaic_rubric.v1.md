# 套路与近重复操作化量规 v1

## 1. 构念定义

“套路”不是“使用了相同词语”，也不是“产品必要语法存在”。本量规将套路定义为：两条或多条内容在核心修辞动作、证据推进和限度功能上同构，差异主要停留在换词、换位置、换人物/物件皮肤或换表面承载。

“近重复”指文本、结构或独特表达达到高重合；它和套路分别记录，最终按人工确认涉及的唯一条目取并集计算 V1.1 比率。

## 2. 判定单位

基本单位是同一候选对；簇是经裁决确认的套路边所形成的连通分量。机器只负责召回候选边，不得用单一余弦、嵌入或 n-gram 阈值直接给条目定罪。

比较范围必须在运行前冻结：

- 同一产品内候选对优先全覆盖；
- 跨产品使用固定算法召回共享全局模板候选；
- 算法版本、阈值、每条最大候选数和比较分母写入运行清单；
- 未被机器召回的随机负样本也必须抽查，以估计候选召回率。

## 3. 六轴首判

两名评审者分别对以下六轴标记 `SAME / DIFFERENT / UNCLEAR`：

| 轴 | 评审问题 |
|---|---|
| A 论证脊柱 | 段落或信息节点之间的主关系是否相同，例如“证据列举→否定边界→静默收尾” |
| B 证据推进 | 事实是按相同的顺序和因果/对照/时间关系推进吗 |
| C 限度功能 | 限度是否承担相同修辞动作，例如免责、延后、缺料静默、泛化回撤 |
| D 视角与锚点 | 岗位、判断入口、时间锚或对象入口是否只是换皮 |
| E 收尾功能 | 结尾是否完成相同功能，例如转交确认、挂起、价值动作、状态快照 |
| F 变换深度 | 两条差异是否主要是 `SURFACE_ONLY`，还是改变了真实论证和用户价值 |

F 轴取值为 `SURFACE_ONLY / STRUCTURAL_CHANGE / UNCLEAR`。

## 4. 固定决策程序

先执行必要语法检查，再执行套路判定：

1. 若二者共享部分完全由产品定义强制，且该例外已在批次前版本化登记，则将这些共享部分标记 `NECESSARY_GRAMMAR`，不参与套路核心计数；
2. 若 A/B/C 中至少两轴为 `SAME`，D/E 中至少一轴为 `SAME`，且 F=`SURFACE_ONLY`，判 `FORMULAIC`；
3. 若 A/B/C 三轴均 `SAME`，即使 F 存在局部结构变化，也进入裁决，不得自动判非套路；
4. 若文本或独特表达显著重合但核心修辞动作不同，单独判 `NEAR_DUPLICATE` 或送审；
5. 两轴以上为 `UNCLEAR`，或首判者跨越 `FORMULAIC / NOT_FORMULAIC`，判 `INDETERMINATE` 并进入第三裁决；
6. 没有满足以上条件且不存在近重复证据，判 `NOT_FORMULAIC`。

允许的最终标签：

- `FORMULAIC`；
- `NOT_FORMULAIC`；
- `NECESSARY_GRAMMAR`；
- `INDETERMINATE`；
- `NEAR_DUPLICATE`，可与 `FORMULAIC` 并存。

## 5. 产品必要语法例外

例外必须在受评批次生成前登记：产品、固定语法、业务必要性、允许范围、不可替代原因、版本和批准者。例外只排除被强制的部分，不能豁免其他共享修辞动作。

禁止：

- 看见批次不通过后补写例外；
- 把同一事实素材造成的任何同构都称作必要语法；
- 用“产品本来就这样”替代可验证的产品定义引用；
- 用例外改变已经冻结的 R5 结论。

## 6. 机器候选召回器

候选召回可以组合：文本归一化、n-gram、结构签名、语义嵌入、条件相似度或语言模型。但必须在独立金标上报告：

- 候选召回率与精确率；
- 未召回正例；
- 每条候选边数及 P95 人审负担；
- 同产品与跨产品分层结果；
- 产品必要语法上的误报；
- 算法和阈值版本。

M0 要求候选召回率不低于 0.95。精确率不能只靠降低召回换取；成本是否可承受由预算合同另行判断。

## 7. 指标计算

```text
套路或近重复条目率
= 涉及至少一条经人工裁决确认 FORMULAIC 或 NEAR_DUPLICATE 边的唯一正向条目数
÷ 当前受评正向首次输出总数
```

簇大小、边数量和条目率同时报告，但不得用边数量替代条目分母。产品必要语法边不进入分子；`INDETERMINATE` 必须完成裁决后才能关闭批次。

## 8. 评审一致性资格

资格集至少 300 个全新双审对，其中正类与负类各不少于 100，对产品必要语法例外不少于 20。报告：

- 原始一致率≥0.90；
- 正类一致率≥0.80；
- 负类一致率≥0.80；
- 类别可解释时加权一致性系数≥0.60；
- 裁决率≤0.20；
- 分家族最差值、类别分布和 95% 置信区间。

量规只允许初版加一次冻结修订（共两个方法版本）。仍不达标时，自动套路门停止；若人工全审在批准预算内，可保留人工路线，但不得宣称机器套路门已合格。

## 9. 反例与变形测试

资格集至少包含：

1. 不同词面、相同修辞动作；
2. 相同事实、不同论证脊柱；
3. 相同必要语法、不同用户价值；
4. 相同开头、不同证据推进；
5. 限度从末段移到中段但功能不变；
6. 相同词语在不同语义功能中出现；
7. 不同产品共享全局免责模板；
8. 产品固定格式的合法例外。
