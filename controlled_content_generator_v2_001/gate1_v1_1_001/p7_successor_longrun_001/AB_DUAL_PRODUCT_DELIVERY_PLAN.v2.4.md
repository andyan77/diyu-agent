### 3.3 会话与状态纪律（冻结）

1. **每个里程碑 = 一个全新 Fable 5 长程会话**，连续执行至接受、诊断完成或诚实停止；**关闭即退出，等待下一个 P，严禁自动续跑下一里程碑**。
2. 跨里程碑状态完全由 **Git + manifest + 证据包 + handoff** 承担，不靠会话记忆/自然语言转述；下一会话只需读取：当前合同集、上一节点关闭回执、本节点输入清单、当前源提交。
3. 模型上下文不是审计系统；每个胶囊至少一个 Git 提交，每个里程碑一个冻结提交+产物摘要（checkpoint 不作审计证据 [静证 官方：不追踪 Bash 修改]）。

### 3.4 里程碑控制面（薄；目录命名与布局=相机）

在既有写面内新增（示例布局，M1 初建）：`p7_successor_longrun_001/delivery_control_001/`——顶层 `MILESTONE_DAG` / `ACTIVE_CONTRACT_SET` / `SOURCE_LOCK` / `ROLE_MODEL_MATRIX` / `STOP_LEDGER`，加 `milestones/M1..M7/`。每里程碑**关闭时**产出八件套：`MILESTONE_CONTRACT / INPUT_MANIFEST / OUTPUT_MANIFEST / EVIDENCE_MANIFEST / STAGE_DECISION / CLOSEOUT_REPORT / CLOSEOUT_RECEIPT / HANDOFF`（需远端锚时加 `ORIGIN_ANCHOR`）。只记路径、摘要、数量、状态、签字，不复制业务代码与材料。**防过度工程化（冻结）**：不预生成空壳，schema 自最小 v1 起按需生长（发起人修复分类三原则）。

### 3.5 代理拓扑（冻结）

```
Fable 5 里程碑负责人（探查/计划/派工/实现/验证/修复/收口）
├── 实现代理 ├── 确定性验证代理 ├── 叙事事实审查代理 ├── 对抗审查代理 └── 证据审计代理
正式独立裁决与最终签发：Codex-GPT（全新隔离会话，从冻结原始事件独立复算）
```

- **两层代理封顶**（避免签字来源与材料可见性失控）；Agent Teams 不作正式状态机（实验性 [静证]）。
- **Fable 5 不得签署自己完成的工作**；正式盲审**禁止使用作者会话的 resume/fork**。
- 隔离必须技术性实现（v2.3 §壹落地纪律 1，E11 前科）。

### 3.6 硬门底座（冻结）

- **可移植底座 = 仓内确定性脚本**（checker + 负向攻击测试 + CI 从磁盘复算终验）；`/run-milestone` 执行器优先实现为**仓内脚本**（如 `run_milestone.py M2`：读合同→校验入口回执→锁输入提交→建工作树→载写面→派工→实现验证→独立复核→证据包→关闭回执→停止），不得自改验收门、不得自动启动下一里程碑。
- **hooks 为加固层非唯一层**：本环境 `.claude/hooks`、`.claude/skills` 在沙箱写保护内 [实测]，hooks 配置属发起人环境层动作；关键门不用异步 hook（无法阻断已发生动作 [静证]）。
- 根 `CLAUDE.md` 只留稳定规则（≤200 行）；里程碑流程入 `MILESTONE_CONTRACT`。

### 3.7 Y 分叉与密封隔离纪律（冻结）

M2 接受后，从同一精确 `M2_SHA` 建两条工作树（A：M3→M4→M5；B：M6→M7）：

1. A/B 各自目录所有权冻结；公共合同分叉后默认只读，公共层修改必须回治理修订流程，不得两线各改一份；A/B 独立事件命名空间；**不设互相牵连的总 ALL_PASS**。
2. 工作树只隔离文件修改、共享 Git 历史，**不是保密边界** [静证]→ **密封载荷（QUAL-A/B、隐藏 40）明文不进入作者可读 Git 历史**；主仓只存摘要、密文或保全回执。
3. 正式盲测运行：**全新非 fork 会话 + `CLAUDE_CODE_DISABLE_AUTO_MEMORY=1`**（自动记忆跨工作树共享 [实测自证]）；运行毕保存调用回执与会话摘要；登记提供方数据保留条件。

### 4.4 物理解耦（交付段）
