# 5. 总执行原则

```yaml
execution_principles:
  P1_source_grounded:
    rule: GPT 5.5 生成内容不是 source anchor。
    consequence: 无 Source Pack 的产物只能是 gpt_generated_draft。

  P2_declared_semantics_first:
    rule: 读取草案声明语义，不重新乱分类。
    consequence: 只有契约冲突、风险证据或字段不可承接时才进入 review / decision。

  P3_no_direct_landing:
    rule: 本计划不直接写 KE / Serving / RAG / DIFY。
    consequence: 所有产物停在 draft / candidate_input / assertion / outbox 层。

  P4_no_parallel_gold:
    rule: 不新建独立 Golden Test 体系。
    consequence: 只生成 gold_hook_candidates，供现有 Step 20 消费。

  P5_readiness_all_false:
    rule: 所有 readiness / generation / production flags 必须 false。
    consequence: 任一 true 直接 blocking。

  P6_capability_composable_or_reject:
    rule: 每条知识必须说明如何被 P0 能力路由消费。
    consequence: 无 capability routing consumability 的知识判为 index_shell 或 source_gap。

  P7_body_structure_consistency:
    rule: rich_body_blocks 不得超出结构卡声明的事实、规则和边界。
    consequence: 正文越界必须回 CandidatePack / SourceGap / DecisionPacket。
```

# 16. failure_code

```yaml
failure_codes:
  KIG_LAYER_UNSUPPORTED:
    meaning: 草案声明层级当前系统无法承接。
    route: decision_packet

  KIG_FIELD_UNMAPPED:
    meaning: required 字段无法映射到当前 contract。
    route: contract_delta_or_rewrite

  KIG_ENUM_MISS:
    meaning: 词表值未命中系统 enum。
    route: enum_alignment_or_decision_packet

  KIG_PAYLOAD_INCOMPLETE:
    meaning: payload 缺 required 字段。
    route: rewrite

  KIG_SOURCE_TYPE_MISUSED:
    meaning: source_type 被误用为本体落层。
    route: boundary_correction

  KIG_HARD_CLAIM_LEAK:
    meaning: hard claim 未剥离或未证据绑定。
    route: blocking_source_gap

  KIG_BRAND_FACT_LEAK:
    meaning: GeneralKB 出现品牌/商品/门店/人物事实。
    route: blocking_brand_specific

  KIG_SOURCE_ANCHOR_MISSING:
    meaning: 缺 source_pack / excerpt / digest。
    route: source_gap

  KIG_DUPLICATE_UNRESOLVED:
    meaning: 语义重复未处理。
    route: review_queue

  KIG_CONFLICT_UNRESOLVED:
    meaning: 规则或父子关系冲突未裁决。
    route: decision_packet

  KIG_BODY_OVERREACH:
    meaning: rich body 超出结构卡声明。
    route: rewrite_or_decision_packet

  KIG_ROUTE_NOT_COMPOSABLE:
    meaning: 知识无法被能力路由组合使用。
    route: rewrite_or_excluded

  KIG_READINESS_LEAK:
    meaning: readiness / generation / production flag 被误置 true。
    route: blocking_reject

  KIG_GOLD_PARALLEL_SYSTEM:
```
